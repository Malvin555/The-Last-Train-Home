# The Last Train Home

*A 2D visual novel about human connection and self-discovery*

## About the Game

**The Last Train Home** is a short, atmospheric visual novel that explores the power of chance encounters. On a quiet train platform late at night, Malvin meets a mysterious stranger. What begins as casual conversation evolves into a profound dialogue about life, regrets, and the choices that define us.

## Features

- **Emotional storytelling** through dialogue and atmosphere
- **Multiple endings** based on your choices
- **Atmospheric visuals** and reflective tone
- **Short playtime** (15-30 minutes) perfect for a single sitting

## Endings

Your choices determine how Malvin's journey concludes:
- **Acceptance**: A hopeful resolution about moving forward
- **Reflection**: A bittersweet look at missed opportunities
- **Farewell**: An open-ended conclusion about letting go

## Built With

- Ren'Py Engine
- Original artwork and writing

## Theme

A meditation on the quiet moments that change us - the conversations we remember, the connections that linger, and the thoughts we carry when no one is watching.

## How to Run

1. Clone or download this repository
2. Install Ren'Py (if not already installed)
3. Open the project in Ren'Py launcher
4. Launch the game

## Notes

This is an experimental narrative project focused on atmosphere and emotional resonance rather than traditional gameplay mechanics. Created as a learning exercise to explore Ren'Py's capabilities in visual storytelling and interactive narrative design.

**Disclaimer:** This is my first Ren'Py project created while learning the engine. The game may contain rough edges, simple artwork, or narrative inconsistencies as I'm still developing my skills in visual novel creation. Feedback is welcome!
